# Agent Workspace

This directory will host OpenAI agent tooling that coordinates with the in-repo resume MCP server. As the agent stack evolves, use this space for:

- Agent orchestration scripts and configuration
- Prompt templates and planning documents
- Integration utilities for connecting to the MCP server

For now, the folder serves as a scaffold. When you are ready to build the agents, copy `.env.example` to `.env`, supply the required secrets, and begin adding code and documentation alongside these resources.
